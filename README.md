## Что сделано

Многораздельная адаптивная страница курса на чистых HTML и CSS (без JavaScript и фреймворков).
Содержимое страницы построено по данным из dataset.

│   └── cover.svg       # обложка на первом экране

## Структура HTML

- `header.site-header` содержит логотип и навигацию `nav` (ссылки ведут на `#about`, `#tracks`, `#schedule`, `#signup`);
- `main` содержит четыре раздела `section` с этими же `id`:
  - `#about`: заголовок `h1`, описание и обложка;
  - `#tracks`: шесть карточек `article` с одинаковым набором классов;
  - `#schedule`: таблица с `thead` и `tbody` (шесть строк, числовой и текстовые столбцы);
  - `#signup`: форма регистрации;
- `footer.site-footer`: подвал страницы.

Иерархия заголовков: один `h1`, разделы `h2`, названия карточек `h3`.

## Применённые приёмы CSS

- `box-sizing: border-box` для всех элементов;
- базовая типографика (шрифт, размер, межстрочный интервал) и ограничивающий контейнер `.container` (`max-width: 1100px`);
- стили заданы классами, внутри HTML нет атрибутов `style`;
- состояния `:hover`, `:focus-visible` для ссылок, кнопок и полей формы;
- Flexbox с переносом (`flex-wrap`) в шапке, на первом экране и в сетке карточек;
- медиазапрос `@media (max-width: 720px)`: шапка перестраивается в колонку, уменьшаются отступы;
- таблица в контейнере `.table-wrap` с `overflow-x: auto`, чтобы на узком экране прокручивалась таблица, а не вся страница;
- состояние ошибки в форме: поля с неверным значением получают красную рамку (`:user-invalid`).

## Форма

Поля: имя (`text`, `required`, `minlength="2"`, `maxlength="60"`), почта (`email`, `required`), направление (`select`, `required`), уровень подготовки (`number`, `min="1"`, `max="10"`, `required`), комментарий (`textarea`, `maxlength="300"`), согласие (`checkbox`, `required`). У каждого поля есть связанный `label`.

## Используемые файлы dataset

| Файл | Где используется |
| --- | --- |
| `data/content.csv` | шесть карточек в разделе «Направления» и шесть строк таблицы «Расписание»; названия из столбца `title` также стали пунктами списка «Направление» в форме |
| `data/navigation.json` | пункты навигации в шапке: поля `label` (текст ссылки) и `target` (`id` раздела) |
| `images/logo.svg` | логотип в шапке (`alt` задан) |
| `images/cover.svg` | обложка на первом экране (`alt` задан) |

Значения из CSV перенесены в разметку вручную, как разрешено заданием. Все пути относительные.

## Как запустить локально

1. Скачать репозиторий (кнопка **Code → Download ZIP**) и распаковать либо выполнить `git clone`.
2. Открыть файл `index.html` двойным щелчком в любом браузере.

Установка дополнительных программ не требуется.

## Проверки

- в Console браузера нет ошибок;
- нет дублирующихся `id`, все ссылки навигации ведут на существующие разделы;
- переход по странице клавишей Tab работает, фокус виден;
- при ширине окна около 390 px нет горизонтальной прокрутки;
- пустая форма не отправляется, неверный e-mail и число вне диапазона 1–10 подсвечиваются.
